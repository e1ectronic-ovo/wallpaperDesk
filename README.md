# 画境

**画境** 是一款开源的 Windows 桌面视觉管理工具，用来整理本地图片与视频，并把它们设为静态或动态桌面。

本项目以 [MIT License](LICENSE) 开源：你可以自由使用、修改、分发，也欢迎提交 Issue 与 Pull Request。

## 功能

- **本地图库**：导入 JPG / PNG / WEBP / GIF / BMP 等图片，一键设为桌面壁纸，支持多显示器。
- **动态桌面**：导入 MP4 / WEBM / MKV 等视频，铺到桌面播放；可调音量、静音、循环。
- **资源管理**：全部 / 图片 / 视频 / 收藏分类浏览；支持搜索、分辨率筛选、排序，以及网格 / 列表视图。
- **预览与详情**：打开资源查看大图或预览视频，收藏或从库中移除。
- **后台运行**：关闭主窗口后程序仍可在系统托盘运行，动态桌面不会中断。
- **开机与恢复**：可选开机自启动，以及启动时自动恢复上次播放的动态桌面。
- **自定义库目录**：导入文件会复制到壁纸库；可改到其他磁盘，避免占满系统盘。
- **紧急停止**：动态桌面异常时，按 `Ctrl+Shift+Alt+W` 立即停止。

退出程序时会还原系统壁纸。关闭窗口不等于退出——请从托盘菜单选择退出。

## 使用

1. 安装或解压后启动 **画境**。
2. 在左侧导入本地图片或视频。
3. 点击资源打开详情：图片选「设为桌面壁纸」，视频选「设为动态壁纸」。
4. 需要停止动态桌面时，可点工具栏 LIVE 条、详情页停止按钮，或使用紧急快捷键。

安装包与便携版构建产物位于 `release/` 目录（执行 `npm run build:win` 后生成）。

## 开发

环境：Node.js 18+、Windows。

```bash
npm install
npm run dev
```

打包 Windows 安装包 / 便携版：

```bash
npm run build:win
```

技术栈：Electron · React · TypeScript · Tailwind CSS。
